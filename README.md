# 🏡 Airbnb Clone – Full Stack Web Application

A full-stack web application inspired by Airbnb that allows users to explore, create, and manage property listings with map integration.

---

## 🚀 Features

- 🔐 User Authentication (Login / Signup)
- 🏠 Create, Edit, Delete Listings
- 🖼️ Image Upload (Cloud storage)
- 📍 Map Integration using Mapbox
- 💬 Reviews & Ratings system
- 👤 Authorization (Only owner can edit/delete)
- 🌐 Responsive UI

---

## 🛠️ Tech Stack

- **Frontend:** EJS, CSS, Bootstrap
- **Backend:** Node.js, Express.js
- **Database:** MongoDB, Mongoose
- **Authentication:** Passport.js
- **Maps:** Mapbox API
- **Cloud Storage:** Cloudinary (if used)

---

## 📂 Project Structure


/models → Database schemas
/routes → Application routes
/controllers → Business logic
/views → EJS templates
/public → Static files (CSS, JS)
